# تاريخ ابن خلدون — ديوان المبتدأ والخبر

تطبيق ويب أوفلاين لقراءة **تاريخ ابن خلدون** (كتاب العِبَر) والمقدمة، بأسلوب مشروعَي
`al-adhkiya` و`mujam-al-buldan`: صفحة واحدة مستقلة، بلا أي اعتماد على CDN خارجي،
مع فهرسة كاملة وبحث فوري في النص وإبراز الكلمات.

## المزايا
- **قراءة أوفلاين 100%** (Service Worker + PWA قابل للتثبيت).
- **فهرس شجري** متعدد المستويات: الأجزاء ← الكتب/الأبواب ← الفصول ← الأخبار.
- **بحث في النص كاملًا** مع تطبيع عربي (إزالة التشكيل، توحيد الهمزات/الألف/الياء)
  وإبراز نتائج المطابقة.
- **تخصيص القراءة**: نوع الخط (أميري / كايرو)، حجم الخط، والوضع (نهاري/ورقي/ليلي).
- **حفظ موضع القراءة** تلقائيًا (localStorage) واستئنافه عند العودة.
- تصميم متجاوب مع قائمة جانبية منسدلة على الجوال.

## إعادة البناء
```bash
node scripts/parse.mjs      # يقرأ data/*.mARkdown ويولّد data/book.json و book-data.js
```
ثم شغّل الموقع محليًا: `python3 -m http.server 8080`.
